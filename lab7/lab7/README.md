
# SindhTech — Lab 7 React Fundamentals

A responsive homepage built using React and React Bootstrap.

## Features
- Responsive navigation bar
- Hero section with call-to-action buttons
- Three feature cards
- Footer with navigation links
- Four reusable React components

## Library
React Bootstrap and Bootstrap CSS.

## Installation
Run `npm install react-bootstrap bootstrap`.

## Run the project
Run `npm install`, then `npm run dev`.

React Bootstrap saves us from writing common UI components such as
navigation bars, buttons, cards, and responsive grid layouts by hand.
